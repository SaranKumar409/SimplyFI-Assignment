# SimplyFI Assignment – DevOps Internship

This project demonstrates containerization of a multi-service application using Docker.

## Services
- Frontend: Nginx
- Backend: Node.js
- Database: MySQL

## Docker Best Practices Followed
- Small and secure base images (Alpine)
- Separate Dockerfiles for frontend and backend
- Clean and optimized image layers

## How to Run
docker-compose up --build
